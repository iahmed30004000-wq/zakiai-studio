# حالة المشروع وقراراته — 22 تشرين الأول 2026

هذا الملف تجميع لـ«ذاكرة الشغل» السابقة، مكتوب لأي مساعد (Hermes + GLM مثلاً) بيكمّل المشروع. الكود والاختبارات هم المرجع الأخير: لو تعارض شي مع الكود صدّق الكود وصلّح هالملف. قواعد الشغل والأوامر بـ `AGENTS.md`.

## 1. المالك وطريقة الشغل (مختصر)

- صاحب متاجر دفع عند الاستلام، لهجته شامية، مش مبرمج. بيبني النظام لإنتاج إعلانات فيديو.
- بيحب الشغل يكتمل لحاله بلا أسئلة صغيرة؛ بيسأل عند قرار حقيقي بس. لما بنترك إله خيارات بيقول «بدي انت تختار»، فنقدّم قرار نهائي ونترك إله اللي ما بيصير إلا منه: سرّ، دفع، دخول، كبسة توليد على حسابه.
- المفاتيح والتوكنات والباسوردات بيدخلها بنفسه. ما بنطلبها بالمحادثة وما بنكتبها بأي ملف.
- لما بيقول «وقف عند التنفيذ» بنكتب القرارات ونستنى كلمة «نفّذ».
- التقارير: لغة مفهومة 100% + مثال واحد، والمصطلح التقني بيتشرح بكلمات عادية أول ما يظهر. وقت القرار: التوصية أول (شو بيصير، ليش، مثال، الثمن) وبعدها باقي الخيارات.

## 2. المنتج بجملة

نظام بيحوّل إعلانات فيديو ناجحة لأنماط قابلة لإعادة الاستعمال، وبيكتب منها سيناريوهات 7 مشاهد (45–50 ثانية) لمنتجات المالك، وبيولّد الصوت والصور والتحريك، وبيمنتج ويصدّر فيديو عمودي 9:16، وبيربط الأداء بالسيناريو. بجانبه «مشروع حر» (إنتاج يدوي من أي نقطة) و«مكتبة النماذج» (ربط أي نموذج مفتوح المصدر أو أوزان على السيرفر، زي كونفي بلا تعقيده).

المهمة الموجّهة (7 مراحل بالواجهة، محطات مرتبة: صوت = 4، صور = 7، مطابقة الصور = 8، تحريك = 9، مونتاج وإطلاق = 10) ما بتتغيّر أبداً. كل ميزة يدوية بتنبني فوقها مشروطة بوضع «حر».

معلّق عند المالك: ينشئ أول حساب بنفسه؛ مفتاح Anthropic المحفوظ مرفوض (401) فالترجمة التلقائية وبطاقة الهوية بتنتظر؛ مفتاح fal.ai للتحريك (Kling/Hailuo ما انجرّبوا حي)؛ يثبّت الإضافة؛ يضبط حد فحص الوجه؛ يولّد صور GPT الستة من `برومبتات_رسومات_الموقع_الجديدة.docx`.

## 9. المشروع الحر + مكتبة النماذج (م1–م7، خلصت 22/10)

المشروع الحر
- ملفات `free__<تاريخ>__<عنوان>`، `_meta.mode="free"`، والخط الزمني `mode:"free"` هو المصدر الوحيد (فيه `rev` لمنع تعارض التعديل) والسيناريو مرآة.
- بداية من فاضي أو نص أو Excel أو صور أو فيديوهات أو تسجيل صوت. شاشتان: «المشاهد واللقطات» (حفظ تلقائي) و«المونتاج والتنزيل» (ffmpeg بكاش وإطارات دقيقة، موسيقى بخفض، مؤثرات، ترجمة، بصمة «قديم»).
- الصوت: رفع تسجيل ← تفريغ ← قص على المشاهد (`voice_upload.py`، `ar_align.py` للمطابقة العربية).
- «⚡ شغلة سريعة» و«✋ يدوي بلا تسلسل»: أبواب فوق نفس المسارات.
- داخل المهمة الموجّهة (بقواعدها): سيناريو بإيدك (`manual_script.py`)، موافقة بالفحص الحسابي (`review_loop.approve_local`، تأكيد على مرحلتين)، رفع صورة أو فيديو للقطة.

مكتبة النماذج
- الملف `library/model_library.json` (مسار بديل `VP_MODEL_LIBRARY`). المهام: صور، تحريك (بسجله `library/motion_models.json`)، صوت، تفريغ، مزامنة شفاه، تكبير، تفريغ خلفية، موسيقى، مؤثرات.
- 4 طرق ربط: `weights` (صندوق الأوزان)، `app` (برنامج Gradio 4+؛ Gradio 3 مرفوض)، `std` (واجهة OpenAI: صور وصوت وتفريغ)، `command` (أمر بلا shell).
- الاختيار `pick()`: `lib:ml_x` صريح ← مزوّد صريح ← افتراضي المهمة ← الطريقة الحالية. بلا رجوع تلقائي للصوت ومزامنة الشفاه والموسيقى والمؤثرات والتحريك.
- بوابة الرخصة، `net_allow`، أسماء التوكنات `modellib.<id>.token` و`modellib.box.token` بس، خزنة مشفّرة بـ `VP_SECRETS_KEY` على لينكس، قفل كرت `gpu_lease.py` (بيشتغل لما `VP_GPU_LOCK_DIR` مضبوط)، قوالب `presets/model_templates.json` (25).
- الصندوق العام `services/engine` (عقد v2): `/health` فيه `api:2` وذاكرة الكرت والنموذج المحمّل وسقف مدة الصوت، `GET /models`، أنماط t2i وi2i وupscale وt2v وi2v وt2a. يرفض أي ملف غير آمن (`.bin .pt .ckpt .pkl .py`، مجلد برابط رمزي، أكتر من 6000 ملف، مكتبة مكوّن غريبة). المكوّن `["stable_audio","StableAudioProjectionModel"]` مسموح بالاسم بس.
- إعدادات الصندوق (بيئة): `ENGINE_TOKEN` (إجباري)، `MAX_SECONDS` (8 بالـ compose)، `AUDIO_MAX_SECONDS` (47)، `MAX_PIXELS`، `UPSCALE_MAX_PIXELS` (64 مليون)، `ENGINE_OFFLOAD`، `OUTPUT_KEEP_MIN`. i2v لنماذج Wan بس لو `expand_timesteps:true` بالـ model_index (TI2V).
- موسيقى ومؤثرات: `sound_gen.py`، المسارات `POST /api/ahat/generate` و`POST /api/studio/{f}/sounds/{rid}/generate`؛ المقطع «غير معتمد»؛ طلب السيناريو بيصير `status:"local"` برمز ونبضة كل 30 ثانية (بيرجع ينتظر بعد 180 ثانية بلا نبضة)؛ `caps.max_sec` بيتفحص قبل الإرسال.
- الإضافات بنفس الجولة: Stable Audio Open (قالبين: موسيقى ومؤثرات، مجاني تجارياً تحت مليون دولار إيراد، التنزيل بـ `--exclude "*.ckpt" "model.safetensors"` وبعد تسجيل دخول Hugging Face).

مطبّات اكتُشفت: Wan بيرجّع numpy افتراضياً (نثبّت `output_type=pil`)؛ LTX-Video فيه ~236 GB بلا `--include`؛ FLUX.1-schnell وStable Audio محميين بتسجيل دخول HF؛ الأوزان الأحادية بجذر المستودع ما بتنحسب بالحجم؛ Gradio 4 بيضيّع الحدث لو بعتنا `session_hash` بالنداء والإلغاء بيكون بـ `session_hash=event_id` وقبل إغلاق اتصال SSE؛ `Path.resolve()` على حلقة روابط بيرمي RuntimeError بـ Python ≤ 3.12.

المراجعة المستقلة (22/10): 16 ملاحظة، 15 اتصلّحت (سقوف حجم أثناء التنزيل، فحص أوزان أصرم، حدود `extra`، التوكن قبل قراءة الجسم، سقف التكبير بالمقياس الأصلي، تصفير تأكيد الرخصة عند تغييرها، قفل ملف الطلبات…). المتروكة: `pick()` بيرجع للطريقة الحالية لو افتراضي الصوت اتعطّل أو انحذف أو الملف تالف (تصميم قديم).

## 10. تشغيل أول مرة على السيرفر (الخطوات)

1. Docker + nvidia-container-toolkit، ثم مرة وحدة: `docker network create vidpattern_net` و`docker volume create vidpattern_gpu_locks`.
2. `.env` من `.env.example` (توكن الصندوق، `VP_SECRETS_KEY`، `APP_UID/APP_GID`).
3. تنزيل الأوزان بمجلد `models/engines` (الأوامر والأحجام والرخص بـ `README_AR_نشر_السيرفر.md`).
4. `docker compose -f docker-compose.engines.yml up -d --build engine` ثم المصنع ← مكتبة النماذج ← «أوزان على السيرفر».
5. أول تشغيل بنماذج حقيقية لازم يكون والمالك قاعد: أي خطأ غريب بيجي من `docker compose logs`.

## 11. أسماء داخلية ما بتتغيّر

خزنة المفاتيح `vidpattern` (keyring)، عقود الـ OMS `/api/vidpattern/*` و`vp:*`، بداية أسماء الإعلانات `VP-`، أسماء النسخ الاحتياطية `vidpattern_backup_*`، متغيّرات `VP_*`، مفتاح `"CRM"` بـ settings.json، قيمة `"crm"` بمصدر حقول البريف، معرّف تبويب `fac-local`.

## 12. تنبيهات بيئة

- ويندوز: Python 3.11، `PYTHONIOENCODING=utf-8` للعربي، سكربتات PowerShell العربية UTF-8 مع BOM، أداة الشيل ممكن تاكل `\` (اكتب سكربتات الباتش بملفات)، ما تستعمل `monkeypatch.undo()`.
- أي تعديل بـ `web/static` لازم يرفع `?v=` بـ index.html وlogin.html معاً. ترانزيشن CSS بالمتصفح الآلي ما بيكمّل: اختبر بإطفائها.
- ترحيل `jobs.created_by` بيصير بإقلاع السيرفر (`jobs.init_db()`): أي فحص بلا أحداث الإقلاع بيطلّع 500 زائف.
- `huggingface_hub` على جهاز المالك بيحتاج شهادات النظام (`truststore`).
