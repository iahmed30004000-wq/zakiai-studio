# المونتاج المتقدّم — شرح بسيط

## شو هو؟
نفس الفيديو العمودي (1080×1920، 30 إطار) لكن برسم أحلى من المونتاج العادي:
- **ترجمة عربية كلمة بكلمة**: الكلمة اللي بتنقال بتضوي بالذهبي مع نبضة خفيفة، والحروف موصولة صح، والكتابة من اليمين لليسار.
- **بطاقة المنتج والسعر**، **بطاقة العرض والضمان**، و**شاشة «اطلب هلأ»** بهوية «ليالي الشرق» (ذهبي وليلي ولازوردي وفيروزي).
- البطاقة اللي بياناتها فاضية (مثلاً السعر فاضي) **بتختفي لحالها**، ما بنخترع شي.
- كل الكتابة بتضل بعيدة عن الـ 22٪ السفلية (المكان اللي بتغطيه واجهة تيك توك وميتا).
- الصوت: صوت المعلّق + الآهات المعتمدة، والآهات بتنخفض لحالها لما المعلّق يحكي، ومستوى الصوت موحّد (-16).

**مثال:** سيناريو اسمه `VP-kama-1-v1` → بيطلع `library/exports/VP-kama-1-v1.mp4`.

المونتاج العادي (`montage.py`) ما انلمس وبيضل شغّال إذا فشل هالمحرّك.

## كيف بتشغّله؟
افتح الطرفية من مجلد المشروع، واكتب:

1. **فحص الجاهزية** (أول مرة وكل ما صار شي غريب):
   ```
   python -m services.advanced_montage doctor
   ```
   بيطبع ✓ أو ✗ جنب كل شي (Node، المتصفح، حزم Remotion، الخطوط، ffmpeg). كل ✗ مكتوب جنبه شو تعمل.

2. **الرندر**:
   ```
   python -m services.advanced_montage render library/scripts/اسم_السيناريو.json
   ```
   بيحضّر الملفات، بيرسم الفيديو، بيفحصه (الحجم والمدة والصوت)، وإذا كله تمام بينسخه لـ `library/exports/`.
   فيديو من 47 ثانية بياخد غالباً 4 – 8 دقايق (الرندر على المعالج مش كرت الشاشة). وفيديو تجريبي 7.6 ثانية أخد عندنا حوالي دقيقة.

3. **لقطة وحدة للمراجعة بالعين** (بدون رندر كامل):
   ```
   python -m services.advanced_montage still library/scripts/اسم_السيناريو.json --frame 60 --png لقطة.png
   ```

## من داخل الموقع (محطة المونتاج)

- زر **«تصدير متقدّم»**: بيشغّل نفس الرندر لهالسيناريو وبينشر الفيديو بنفس مكان التصدير العادي (`library/exports/<script_id>.mp4`). محطة الإطلاق ما بتحس بالفرق.
- خانة **«خلّي صدّر نهائياً دايماً بالمتقدّم»**: لما تتفعّل، زر «صدّر نهائياً» العادي بيجرّب المتقدّم أول، ولو فشل (Node/Chrome ناقص، فحص الناتج…) بيكمّل لحاله بالتصدير العادي. (الإعداد `MONTAGE_FINAL_ENGINE` بـ settings.json: `ffmpeg` الافتراضي أو `remotion`.)
- المعاينة دايماً بـ ffmpeg السريع.
- فحص الجاهزية بدون رندر: `GET /api/montage/advanced/doctor`.

## شو بيصير إذا فشل؟
الرسائل بتطلع بالعربي وبتقلك شو ناقص:

| الرسالة | شو تعمل |
|---|---|
| Node.js مش مثبّت | نزّله من nodejs.org (الإصدار 18 أو أحدث) |
| المتصفح (Google Chrome) مش موجود | ثبّت Chrome، أو حط مساره بالمتغيّر `VP_CHROME`. **ما بننزّل متصفح لحالنا.** |
| حزم Remotion مش منزّلة | من مجلد `services/advanced_montage/remotion` شغّل `npm ci` |
| الرندر أخذ أكتر من المهلة | جرّب `--timeout 3600` أو `--concurrency 2` (توازي أقل) |
| فشل الرندر (رمز …) | بنعيد المحاولة مرة تلقائي بتوازي أقل. إذا فشل كمان: بتلاقي سجل كامل بملف `render.log` داخل مجلد `work` جنب الناتج |
| الفيديو طلع بس ما طابق المواصفات | ما بينسخ لـ exports. الملف للمراجعة بمجلد `work/out` |

وإذا ضل فاشل: استعمل المونتاج العادي `python montage.py final library/scripts/…` — بيشتغل مستقل.

## شو اللي نزّلناه؟
- **حزم npm فقط** (بدون أي تنزيل متصفح): `remotion` و`@remotion/cli` و`@remotion/renderer` و`@remotion/bundler` بالإصدار **4.0.530 مثبّت بالضبط**، مع `react` و`react-dom` و`typescript`. مثبّتة بـ `--ignore-scripts` وبملف `package-lock.json`.
- الحجم الفعلي لـ `node_modules`: **حوالي 272 ميغا** (305 حزمة)، وبعد أول رندر بيزيد حوالي 160 ميغا «كاش» بسيط داخل `node_modules/.cache` (بتقدر تمسحه بأي وقت).
- الخط: IBM Plex Sans Arabic (رخصة OFL) منسوخ محلياً بمجلد `remotion/fonts`. **ما في ولا اتصال بالإنترنت وقت الرندر من كودنا.**
- ملاحظة: متصفح Chrome نفسه ممكن يعمل اتصالات خلفية صغيرة لخدمات Google (تحديثات/إشعارات) أثناء الرندر؛ بدون أي علاقة بمحتوى الفيديو. بتقدر تحجب الشبكة عن العملية بجدار الحماية إذا بدك.
- ما نسخنا ولا سطر من `openmontage` ولا `third_party`؛ كل الكود مكتوب من الصفر.
